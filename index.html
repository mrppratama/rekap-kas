BACKUP, RESTORE & IMPORT DATA

Amankan data kas Anda secara berkala atau pindahkan ke komputer lain

Backup Data Database

Unduh seluruh data (Siswa, Periode, Pemasukan, Pengeluaran, Kategori, Pengaturan) menjadi satu file JSON aman.

Restore Data (JSON)

Pulihkan data kas dari file backup JSON sebelumnya. Dilengkapi dengan pratinjau data sebelum konfirmasi.

Import dari File Excel

Import data dari spreadsheet KAS 9A AB2 Juni.xlsx. Sistem akan membaca, memetakan, dan menampilkan pratinjau.
